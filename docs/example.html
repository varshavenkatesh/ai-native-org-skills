The idea

Every meeting a team has produces context that usually evaporates — decisions made in a standup, a renewal risk raised in a customer call, priorities set in a strategy session. The hub captures all of it in two forms:

🧠 Markdown — for agents
Committed to main. Entity pages, decision logs, ADRs. This is what /RESOLVER reads to answer questions.
👀 HTML — for humans
Published to gh-pages. Tiles, badges, and cross-links anyone on the team can browse — no terminal required.
One team, configured once
A single block in config/teams.yaml tells Claude where every artifact for the Payments team should go.
