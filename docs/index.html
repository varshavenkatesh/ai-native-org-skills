Get started in 4 steps

1
Clone and open in Claude Code
git clone https://github.com/varshavenkatesh/ai-native-org-skills then claude
2
Configure your teams
Copy config/teams.example.yaml to config/teams.yaml and fill in Jira, GitHub, Slack, and reviewer details for each scrum team.
3
Set environment variables
Add JIRA_API_TOKEN, JIRA_EMAIL, and SLACK_BOT_TOKEN to your shell profile. Run gh auth login for GitHub.
4
Run your first digest
/RESOLVER samples/standup-2026-05-02.txt — try the included sample transcript to see the full review panel.
