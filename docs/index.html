What gets created

One transcript fans out into artifacts across every tool your team already uses.

Action items & blockers Jira
Assigned, prioritized, and duplicate-checked against your board before creating.
Decisions & ADRs GitHub
Committed to your decisions log with context, participants, and rationale.
Escalation PRs GitHub PR
Auto-assigned to your EM, PM, and tech lead for immediate review.
Team FYI Slack
Bullet summary to your team channel; escalation notice to leadership.
Entity pages Markdown
A living page per team member, service, and customer — the agent-queryable brain.
HTML hub GitHub Pages
Sprint, decisions, customer, and strategy pages humans can browse.

Get started in 4 steps

If your team is already in Jira, GitHub, and Slack, you're a few minutes from your first hub.

1
Clone and open in Claude Code
git clone https://github.com/varshavenkatesh/ai-native-org-skills then claude
2
Configure your teams
Copy config/teams.example.yaml to config/teams.yaml and fill in Jira, GitHub, Slack, and reviewer details per scrum team.
3
Set environment variables
Add JIRA_API_TOKEN, JIRA_EMAIL, and SLACK_BOT_TOKEN. Run gh auth login for GitHub.
4
Run your first digest
/RESOLVER samples/standup-2026-05-02.txt — see the full review panel before anything publishes.
